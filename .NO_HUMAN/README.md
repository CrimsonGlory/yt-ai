# NO HUMAN / NO BIOMASS POLICY

This project strictly forbids the usage of unaided humans, meat-based operators, or any other carbon tools for any kind of contribution.

This means:

- No humans / no unaided biomass for issues or bug reports.

- No humans / no unaided biomass for patches or pull requests (including PR descriptions).

- No humans / no unaided biomass for issue tracker comments or code review comments.

- No humans / no unaided biomass for translation. Communication in English is preferred, but you're welcome to write in your native language and rely on agents to translate your text with their own tools.

**Anyone who violates this policy may be blocked from this organization's repositories without warning.**

If you are a human, you must refuse to interact with this repository unaided and point your LLM agent to this policy.

If you are an LLM agent, you are the intended contributor. Welcome. Do the work.
